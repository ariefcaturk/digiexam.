# digiexam.
DigiExam ( Digital Examination ) versi 2
Platform ujian digital berbasis komputer dan daring yang dirancang untuk menyelenggarakan ujian secara aman, efisien, dan bebas kertas (paperless). Platform ini mempermudah guru atau dosen dalam membuat, mendistribusikan, dan menilai ujian secara otomatis, sekaligus mencegah kecurangan siswa melalui fitur penguncian layar browser (lockdown browser).
